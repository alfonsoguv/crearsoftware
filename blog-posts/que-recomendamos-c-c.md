Un compañero del Blog me preguntó esto por correo y aquí le respondo: Las herramientas que recomendamos para ***programar en C++ bajo Windows*** (para otras plataformas existen otros IDE, como Eclipse con GCC)

-   IDE : Visual Studio 2005
-   Control de código fuente : Perforce
-   Librerias multiplataforma : QT 4.3

Libros hay muchos y variados en C++, dependiendo del nivel del que se comienza.
