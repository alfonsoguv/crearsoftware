## Herramientas para programar en C++ bajo Windows

Las herramientas que recomendamos para ***programar en C++ bajo Windows*** (para otras plataformas existen otros IDE, como Eclipse con GCC) son:

-   **IDE**: Visual Studio 2005
-   **Control de código fuente**: Perforce
-   **Librerías multiplataforma**: Qt 4.3

## Libros recomendados

Libros hay muchos y variados en C++, dependiendo del nivel del que se comienza.

En Qt, el mejor es: [C++ GUI Programming with Qt 4](http://books.google.ie/books?id=tSCR_4LH2KsC&dq=c%2B%2B+gui+programming+with+qt+4&pg=PP1&ots=E6U_pS3bDg&sig=cRdHYqtuWbqXIRFngxrRtVpMweA&hl=en&prev=http://www.google.ie/search?q=C%2B%2B+GUI+Programming+with+Qt+4&ie=utf-8&oe=utf-8&rls=org.mozilla:en-US:official&client=firefox-a&sa=X&oi=print&ct=title&cad=one-book-with-thumbnail)
