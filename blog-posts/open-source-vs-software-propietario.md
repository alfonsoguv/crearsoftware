Navegando por la red, me encontré este interesante [artículo](http://blogs.cnet.com/8301-13505_1-9789275-16.html?tag=blg.orig) sobre el open source y el software propietario. En él se muestra el resultado de una encuesta a más de **228 empresas**, en la que se pedía información sobre las ventajas del open source frente al software propietario y viceversa.

## Las ventajas del open source

Lo primero que llama la atención es que el **80% de los encuestados** cree que la mayor ventaja del open source es el precio. Creo que este es uno de los principales problemas del movimiento, y lo he comentado varias veces: el error de confundir *Free* con *"Libre"*.

El resto de ventajas valoradas fueron:

- **57%** valora positivamente el acceso al código fuente y la independencia que ello aporta.
- **41%** valora las revisiones de código que hace la comunidad (más vale cuatro ojos que dos).
- Con menor porcentaje aparecen ventajas como la seguridad, la calidad o la funcionalidad.

## Las ventajas del software propietario

![Software propietario vs software libre](/wp-content/uploads/2007/10/proprietary_-_advantages_over_open_source.gif)

En cuanto a las ventajas del software propietario o *"commercial"*, en primera posición tenemos la calidad del vendedor (**65%**); es decir, la calidad del "canal de venta". Este punto está reñido con el anterior (el precio): hasta que el open source no sea un buen negocio para el desarrollador, el implantador o el consultor, no habrá calidad ni seguridad en la venta de soluciones open source.

> Se debe superar la leyenda de que el open source es más barato para que el desarrollador de software pueda ganar dinero con los nuevos modelos de negocio.

Al final, como [he comentado anteriormente](/2007/09/23/%c2%bfcuando-se-impondra-el-open-source/), faltan tecnologías y modelos de negocio para el desarrollador de software.

La siguiente ventaja del software propietario, con un **47%**, es la facilidad de adopción por parte de la organización. Creo que esta ventaja está desapareciendo: la nueva generación trabaja con Linux, pronto llegará a las empresas y la adopción de sistemas abiertos será mucho más fácil.

## Ventajas temporales

Creo que el resto de ventajas que destaca el informe son temporales, derivadas de la falta de proveedores profesionales en el ámbito del open source TIC. Faltan empresas que implanten soluciones open source de forma profesional en la PYME. La automatización de actualizaciones (**44%**), el soporte (**35%**), la funcionalidad, la seguridad o la calidad del software son ventajas temporales, provocadas por un movimiento que aún no está lo suficientemente maduro para la empresa.
