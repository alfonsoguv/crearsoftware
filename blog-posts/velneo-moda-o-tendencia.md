La moda es algo puntual, efímero y que no a terminado de calarnos cuando la siguiente ola de modas se hace con el liderazgo. Pero **la tendencia llega para quedarse**, para empaparnos y para hacernos la vida más cómoda. Como usuarios nos volvemos más exigentes, tenemos más información, estamos más comunicados y por tanto variamos en nuestras pretensiones. Queremos: Queremos la música libre en Internet. Queremos disfrutar de las películas haciendo un clic. Queremos tener libertad para usar un software. Queremos tener libertad para estudiar como funciona. Queremos tener libertad para saber como funciona y distribuir copias. Queremos tener libertad para mejorar el software. Queremos acceder a información “no manipulada”. **Queremos compartir Conocimiento e Ideas.** Cuando una tendencia llega, no se puede parar, se le pueden poner obstáculos que retrasen su implantación como está pasando con el software libre, o con la música y el DRM, pero al final la tendencia se implanta porque el usuario sabe lo que quiere. Durante muchos años se nos enseño que para hacer un programa para una empresa teníamos que aprender diferentes y variados estándares , herramientas, bases de datos, servidores Web, plataformas, servidores de aplicaciones, …. Velneo no está diseñado para competir, sino para implantar la tendencia de que para hacer software para empresas no hay que complicarse la vida, para hacer lo complicado sencillo y para demostrar que los usuarios sabemos lo que queremos
